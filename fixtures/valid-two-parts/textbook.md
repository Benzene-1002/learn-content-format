### 3.2.2 第2正規形 {#ch03-02-02}

| 正規形 | 条件 |
| --- | --- |
| 第1 | 繰り返し項目が無い |
| 第2 | 部分関数従属が無い |

### 3.3.1 SELECT {#ch03-03-01}

`SELECT` は表から行を取り出す。計算量は $O(n)$ 程度になることが多い。

```sql
SELECT id FROM users;
```
